# Data and software rights

**Dataset.** The three files in `data/raw/` are unchanged copies of *Indoor occupancy ground truth dataset with variable ventilation*, version 1.0, Julius Mikala, Yinda Xu and Matti Huotari (2026). The authors release the dataset under Creative Commons Attribution 4.0 International. VentLab produced the analysis, window-level estimates and evaluation reports. [Source record](https://doi.org/10.5281/zenodo.18299691) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

**Original software.** The Python implementation and tests are original VentLab project work. The repository includes the MIT license for its software. See [LICENSE](LICENSE). The dataset's CC BY 4.0 grant applies to the source dataset. NumPy, pandas and SciPy retain their respective software licenses.
